# Code of Conduct

This project wants to be a friendly place for everyone who uses it or helps with it, whatever their experience, background or identity.

## Expected behaviour

- Be kind and patient, especially with newcomers.
- Assume good intentions, and discuss ideas rather than people.
- Accept constructive criticism, and give it constructively.
- Respect the time of others: search existing issues before opening a new one, and keep discussions on topic.

## Not acceptable

- Harassment, insults, or derogatory comments about anyone's person, identity or background.
- Sexualised language or imagery, threats, or encouraging others to do any of this.
- Publishing other people's private information without their permission.
- Using the project to promote the sale of counterfeit cards, or proxies for sanctioned tournaments.

## Reporting

If someone's behaviour makes you uncomfortable, contact the maintainer privately through their GitHub profile. Reports are handled confidentially.

The maintainer may edit or remove comments, issues and pull requests, and may block people from the project, when this code is not respected.

## Scope

This code applies in every project space (issues, pull requests, discussions) and when someone represents the project elsewhere.

This code of conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org).
